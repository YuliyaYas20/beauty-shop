# Доменна модель та сутності проєкту Beauty Shop

## 1. Піддомени (Bounded Contexts)

1. **Каталог (Catalog Context)** — відповідає за асортимент косметики, категорії, ціни та опис товарів[cite: 61].
2. **Користувачі (Users & Auth Context)** — відповідає за облікові записи покупців та адміністраторів, їхні ролі та дані профілю[cite: 61, 62].
3. **Замовлення (Orders Context)** — відповідає за формування кошика, оформлення та відстеження статусу замовлень[cite: 61].

## 2. Ключові сутності та атрибути

### Піддомен «Каталог»

- **Product (Товар)**
  - `id` (number/string) — унікальний ідентифікатор товару
  - `name` (string) — назва косметичного засобу
  - `brand` (string) — бренд виробника
  - `category` (string) — категорія (догляд за обличчям, макіяж тощо)
  - `price` (number) — ціна товару
  - `description` (string) — опис та склад
  - `stockQuantity` (number) — залишок на складі

### Піддомен «Користувачі»

- **User (Користувач)**
  - `id` (number/string) — унікальний ідентифікатор
  - `name` (string) — ім'я користувача
  - `email` (string) — електронна пошта (логін)
  - `passwordHash` (string) — захешований пароль
  - `role` (enum: `'customer' | 'admin'`) — роль у системі

### Піддомен «Замовлення»

- **Order (Замовлення)**
  - `id` (number/string) — номер замовлення
  - `userId` (number/string) — посилання на покупця
  - `items` (OrderItem[]) — список позицій у замовленні
  - `totalPrice` (number) — загальна сума до сплати
  - `status` (enum: `'new' | 'confirmed' | 'shipped' | 'completed'`) — статус замовлення
  - `createdAt` (Date) — дата створення

- **OrderItem (Позиція замовлення)**
  - `productId` (number/string) — ідентифікатор товару
  - `productName` (string) — назва товару на момент покупки
  - `quantity` (number) — кількість одиниць
  - `unitPrice` (number) — ціна за одиницю на момент оформлення
